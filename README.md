# Israel Oheji ABI — personal portfolio

A responsive portfolio introducing Israel Oheji ABI's clinical work, research interests, teaching, and health technology projects.

Expected public address: https://drabi-md.github.io/

## Local preview

No build step or third-party dependencies.

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.

## Editing

- `index.html`: biography, projects, research interests, teaching and contact links.
- `styles.css`: responsive design.
- `script.js`: accessible mobile navigation.
- `favicon.svg`: initials icon.

The spine dashboard preview is an illustration, not a chart of observed clinical results. Its linked demonstration uses entirely synthetic patients. Research experience is presented without claims about publication status or clinical effectiveness.

Portfolio content is based on owner-supplied background. Update qualifications, roles, contact details, and project descriptions as they change. No analytics, form backend, external fonts, or visitor data collection are included.
